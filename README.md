Project Description

In this project, I worked with AWS S3 using the CLI. The steps I followed:
	1.	Created a new S3 Bucket using the AWS CLI.
	2.	Uploaded an Object to the Bucket.
	3.	Made the Object publicly accessible by:
	•	Disabling Block Public Access on the Bucket.
	•	Enabling Access Control List (ACL) on the Object.
	•	Granting Read permission for everyone on the Object.

The goal of this project is to understand how to manage S3 Buckets and Objects using the CLI and control their access permissions for public availability
